# FishMarco — 生活俠的小幫手

<img src="assets/logo.png" alt="放大版簡約漸層魚形 Logo" width="160">

Windows 鍵盤／滑鼠自動化工具，以 C#、Windows Forms 與 .NET Framework 製作。支援動作範本、範本組合、多選編輯、拖曳排序及循環執行。

## 建置與執行

在 Windows 執行：

    build.cmd
    FishMarco.exe

使用系統內建的 .NET Framework 4.x C# 編譯器，不需要 NuGet 套件。建置會將 assets/app.ico 嵌入執行檔，供檔案總管、視窗與 Windows 工作列使用；執行時不需要另外攜帶圖示檔。若相同位置的舊版仍在執行，請先關閉再建置覆寫。

## 動作範本

- 支援滑鼠點擊、鍵盤按壓及等待。拖曳十字設定滑鼠位置；鍵盤預設 Space，可直接輸入或「捕捉按鍵」。
- Ctrl／Shift 多選，拖曳排序。雙擊適用欄位可直接修改。
- 右鍵「複製」立即在所選動作下方新增獨立副本；「修改」支援同類型動作的選擇性批次修改；「刪除」移除所選項目。
- 上方「套用至所選動作」將編輯區的完整設定套用到所有選取動作。
- Ctrl+Z 復原動作清單編輯。清單取得焦點時，Ctrl+C／Ctrl+V 複製貼上、Del 刪除；文字編輯中保留文字欄位的快捷鍵行為。
- 動作後等待、循環後等待以秒設定，預設顯示 1.0，可保留至小數點後三位；按住時間以 ms 設定。舊範本的毫秒資料會正確換算。
- 單一動作範本的循環次數不存入範本，程式啟動預設為 0（持續），載入範本不覆寫目前設定。
- Ctrl+S 儲存到目前檔案；尚未儲存過的範本會開啟另存新檔。
- 離開未儲存範本時，可選「確定」放棄修改、「取消」返回，或「儲存並關閉」。取消儲存或儲存失敗時不會離開。
- 右下角「顯示／關閉螢幕點位」切換座標標示。

## 範本組合

加入多個範本，依清單順序執行，例如 A × 2 → B × 3。每列範本的次數須為 1～1,000,000。

- 支援 Ctrl／Shift 多選、拖曳排序、Ctrl+C／Ctrl+V 及 Del。
- 上方同列提供「範本循環次數」「循環後等待」「範本切換等待」。選取會帶入數值，修改任一數值會立即套用至所有選取範本的該欄位。
- 可雙擊範本名稱、循環次數或等待時間直接修改。表格不顯示動作數。
- 右鍵「修改範本」切回主視窗的動作編輯頁面，切換前先檢查未儲存變更。儲存後同步更新該組合項目的內容與來源路徑。
- 「範本切換等待」是目前範本全部執行完，到下一列範本之前的等待；最後一列不額外套用此等待。

### 整個組合的循環

執行列左側的「循環次數（0＝持續）」與「循環後等待 (sec)」控制整個清單：

- 預設執行 1 次。設為 2 時，整份 A → B 清單會跑兩遍。
- 設為 0 時持續循環，按 F10 停止。
- 循環後等待只在整份清單完成、準備開始下一遍之前套用。
- 這兩個設定會隨組合檔與自動保存記錄。舊組合檔預設維持執行 1 次。

淺藍色預估時間列計入按住時間、動作等待、各層循環等待、範本切換及一次開始前的 3 秒倒數。持續循環時不顯示有限總時長。實際執行可能因系統排程而稍長。

### 自動保存與來源檔案

關閉範本組合與正常關閉軟體時，自動保存最新狀態到：

    %LOCALAPPDATA%\EvaMacroStudio\last-sequence.json

為保留舊版資料相容性，自動保存仍沿用 EvaMacroStudio 資料夾。下次啟動並開啟範本組合，即可接續使用。自動保存獨立於手動組合檔，不會覆寫手動儲存的組合檔。

組合包含動作副本與來源路徑。來源檔遺失時會跳出警示並在列旁顯示驚嘆號，動作副本仍保留。舊組合若沒有來源路徑，需重新加入範本才能檢查來源檔。

## 執行提示與快捷鍵

| 操作 | 快捷鍵 |
| --- | --- |
| 開始主視窗動作範本 | F9 |
| 停止目前動作／整個範本組合 | F10 |
| 儲存動作範本 | Ctrl+S |
| 復原動作清單編輯 | Ctrl+Z |
| 複製／貼上清單項目 | Ctrl+C／Ctrl+V |
| 刪除清單所選項目 | Del |

執行前倒數 3 秒。執行中提示顯示範本、剩餘次數、下一個動作種類與倒數秒數，以及「按 F10 停止」。範本組合由「執行組合」按鈕啟動。F9／F10 為保留熱鍵；若 F10 註冊失敗，程式不允許啟動自動操作。

## 測試

    FishMarco.exe --self-test

內建測試涵蓋資料儲存、復原、複製貼上、批次編輯、拖曳排序、各層循環與取消、時間估算、自動恢復及嵌入圖示。測試不會送出實際桌面鍵鼠操作，會在執行檔旁產生結果、測試資料及離屏介面預覽，也不會改寫使用者的自動保存檔。

## 原始碼與資產

- MacroStudio.cs：主視窗、動作編輯、復原與儲存。
- Sequences.cs：範本組合、各層循環、自動保存與時間估算。
- Editing.cs：動作修改、按鍵捕捉、十字拖曳及未儲存警示。
- Interaction.cs：清單多選拖曳、雙擊事件與倒數。
- LiveUI.cs：執行提示、儲存格編輯及程式圖示。
- BatchEditing.cs：選擇性批次修改與秒數格式。
- FeatureTests.cs：功能與介面測試。
- assets/logo.png：放大的藍色漸層魚形、上下魚鰭與白色扳手，無 E 背景的簡約白底 Logo。
- assets/app.ico：16～256 px 多尺寸 Windows 圖示。
- [Logo 生成紀錄](assets/logo-prompt.md)：生成方式與完整提示詞。
